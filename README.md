## Основные проекты

### Orto-N-L-M

AI-система для обучения сотрудников и формирования базы знаний компании.

Система проводит интервью с сотрудником, структурирует полученные знания в Process JSON и использует их для автоматического формирования обучающих материалов.

**Стек:** n8n, OpenAI API, Telegram, PostgreSQL, Docker, Linux/VPS.

[Репозиторий Orto-N-L-M](https://github.com/AlekseyHorjakov/Orto-N-L-M)

### JARVIS

Персональный AI-ассистент с долговременной памятью, инструментами и модульной архитектурой.

Основные компоненты:

- долговременная память;
- PostgreSQL + pgvector;
- OpenAI API;
- AI Agent;
- Tool Calling;
- Telegram;
- Docker;
- SSH и Docker-инструменты;
- поиск через SearXNG.

[Репозиторий JARVIS](https://github.com/AlekseyHorjakov/JARVIS)
